# 动物类建模技巧（animal-modeling.md）

> 适用范围：用 `blender-modeling` 技能做**动物类**模型——哺乳动物、鸟、鱼、昆虫；低多边形/卡通/写实简化三种风格。
> 前置：`AGENTS.md`（阶段/闸门/看图清单唯一权威）、`references/modeling-recipes.md` §0（通用骨架、六条硬规则、材质速查）。本文只讲动物特有的部分。
> 代码块约定同 `modeling-recipes.md` §0.3：接在通用骨架建模段（`build()` 内），最终对象名 `main`；颜色是 0-1 **线性** Base Color，单位米；尺寸/配色/报错来自本机 Blender 4.0.2 实测（§10）或标注的常识值。

> 效果预览：![动物建模示例（低模猫 / 展翅海鸥）](../docs/previews/animal.png)

## 1. 适用范围与风格分级

### 1.1 什么时候用这篇

- 用户要"猫/狗/马/鹿/鸟/鱼/蝴蝶"等**有生命体征**的对象：有头、躯干、四肢/翼/鳍、尾，先解决**物种剪影**再谈部件。
- 器物配方在 `modeling-recipes.md`；动物从躯干骨架起步，拆解顺序不同，且成对件多、比例容错窄。不做毛发粒子、骨骼绑定与动画，本轮只交付静态网格 + 材质 + 多角度渲染。

### 1.2 三种风格与面数预算

| 风格 | 判定特征 | tris 预算 | 分段建议 | 典型交付 |
| --- | --- | --- | --- | --- |
| 低多边形 `lowpoly` | 面块感、硬棱、无毛羽；`shade_flat` | 300-1200 | 球 12×8、圆柱/锥 8-12 | 游戏道具、图标、网页 3D |
| 卡通 `stylized` | 头大 1.5-2×、腿短粗、圆润；`shade_smooth` | 1200-3000 | 球 16×10、圆柱 12-16 | IP 角色、玩具、插画 |
| 写实简化 `semi-real` | 真实比例、有耳/角/蹄/翼细节、无毛发 | 3000-6000 | 球 24×12 + subsurf 1 | 展示、电商、建筑配景 |

写实简化超出 AGENTS 的"低模 <3000 tris"默认值，**必须在 brief 与交付说明里写明**，否则按低模处理。

### 1.3 面数预算与取舍

| 部位 | 低模占比 | 说明 |
| --- | --- | --- |
| 躯干（胸/腹/臀） | 25-35% | 决定剪影，舍得给分段 |
| 头 + 吻 | 15-20% | 头小会立刻"不像" |
| 四条腿 | 15-20% | 8 段圆柱足够 |
| 耳/角/尾/翼/鳍 | 10-15% | 辨识件，宁少勿碎 |

口诀：**先保剪影（躯干/头/腿三条主轴），再保辨识件（耳/角/尾/翼/鳍），最后才是五官**。800 tris 剪影对的猫，比 3000 tris 剪影错的猫更像猫。

## 2. 结构拆解模板

### 2.1 动物四层拆解法

| 层 | 内容 | 常用图元 | 数量 | 顺序 | 通过标准 |
| --- | --- | --- | --- | --- | --- |
| 躯干骨架层 | 躯干（胸/腹/臀）、颈、尾根 | `sphere`+`scale_obj`、`cone` | 2-4 | 最先 | 只看剪影能分出四足/鸟/鱼 |
| 头尾四肢层 | 头、吻、耳/角、腿、尾、翼/鳍 | `sphere`/`cone`/`cylinder`/`tube`/压扁球 | 4-10 | 第二 | 站姿成立、四肢着地 |
| 五官与毛羽细节层 | 眼、鼻、嘴、毛片/羽片、斑纹 | 小球、小锥、薄压扁球 | 0-6 | 前两层通过后 | 物种特征可辨、表情不惊悚 |
| 环境层 | 地台、树枝/石头/水面 | `setup_floor`、`plane`/`cube` | 0-3 | 最后 | 不参与自动取景（用 kit 地台） |

与通用四层的映射：躯干骨架层 = 主体层，头尾四肢层 = 附件层，五官毛羽 = 细节层，环境 = 场景层。动物多一条纪律：**躯干骨架层没通过 build + 三视图，不许写头尾四肢**。

### 2.3 拆解纪律

1. 先量后建：§3 的尺寸先算好写进 brief，再拆部件。
2. 主体不过 build + 三视图，不加耳/尾/五官。
3. 拆不出图元构造 = 拆法不成立，回上一层重拆；低模部件总数 ≤15，超了合并小件；四肢/翼/鳍先写数字（x 左右、y 前后、z 落地）再进脚本。

### 3.1 比例口诀（先调这几个）

- 四足：体长/肩高——猫狗 **1.8-2.0**（短腿厚身），马鹿 **1.4-1.5**（长腿薄身）。比例不对先改这个比值；胸深 ≈ 肩高 35-40%，腿长（肘到地）≈ 肩高 45-55%，头宽 ≈ 体长 0.20-0.28。
- 鸟：翼展 ≈ 体长 2-2.5（海鸥 2.5-3）；头 ≈ 体长 1/4-1/3；尾羽 ≈ 1/3 体长；站姿腿长 ≈ 站高 1/4。
- 鱼：体高 ≈ 体长 1/3-1/2（金鱼更扁）；尾鳍 ≈ 体长 1/4；眼在头长 1/3 处。
- 幼崽/卡通：头 ×1.5-2，腿 ×0.6-0.75，眼 ×1.3-1.6，身体缩到 0.8。量法统一后再进 brief；`dimensions` 与 brief 误差 ≤10%。

## 4. 技巧库

### 4.1 剪影优先法

- **适用/做法**：任何动物首轮。只建躯干+头+四条腿，`--stage build` 看 dimensions，`--stage render` 后三视图 3 秒判"这是猫/马/鸟吗"；能认再加耳/尾/五官，不能认只调三条主轴尺寸。
- **参数/坑**：躯干三段椭球总长 ≈ 体长 1.05-1.15；腿柱上端埋进躯干 15-20%；头径 ≈ 体长 0.13-0.15（猫）/0.10（马）。坑：首轮就加耳尾五官，剪影错了要全拆；只看 iso——front 最能暴露左右不对称与腿间距。

```python
body = sphere("cat_body", radius=0.110, segments=12, rings=8,
              location=(0, -0.02, 0.185), material=fur)
scale_obj(body, (0.75, 1.70, 0.85))          # Y 拉长 = 体长方向
```

### 4.2 四足原型：躯干椭球 ×3 + 腿柱 + 头楔

- **适用/做法**：猫/狗/兔/马/鹿/牛/羊——所有四足。躯干拆 **胸**（前、最宽）→ **腹**（中、最长）→ **臀**（后、上翘）三段椭球；颈用 `cone` 斜插；头 = 1 球 + 吻球/锥；腿 8 段圆柱；脚掌压扁球。
- **参数/坑**：三段半径比 ≈ 1 : 1.3 : 1（腹最大），段间重叠 20-30%；腿径 = 肩高 8-11%（猫狗）/6-8%（马鹿）；头球 r ≈ 头宽 0.55。坑：三段同尺寸 → 香肠；胸腹缝在侧视露接缝 → 加大重叠；腿插太浅浮在体侧。

```python
def ellipsoid(name, loc, radius, scale, material):
    obj = sphere(name, radius=radius, segments=12, rings=8, location=loc, material=material)
    scale_obj(obj, scale)
    return obj

parts = [ellipsoid("cat_chest",  (0,  0.120, 0.195), 0.078, (0.92, 1.05, 1.00), fur),
         ellipsoid("cat_body",   (0, -0.020, 0.185), 0.110, (0.75, 1.70, 0.85), fur),
         ellipsoid("cat_haunch", (0, -0.130, 0.180), 0.082, (0.95, 1.00, 0.95), fur)]
```

### 4.3 图元选择表：头/吻/耳/角/尾/喙/鳍

| 部件 | 首选图元 | 参数经验 | 坑 |
| --- | --- | --- | --- |
| 头 | `sphere` | r ≈ 头宽 0.55，可略扁 | 头比躯干厚 → 像仓鼠 |
| 吻/脸 | `sphere` 压扁 scale(0.92,1.05,0.72) | 长 ≈ 头径 0.5-0.6 | 吻伸出太多 → 像猪/鼠 |
| 耳 | `cone` 8 段，后仰 10-20° | 猫耳高 ≈ 头径 0.45；马耳更长 | 耳根必须埋进头球 15% |
| 角 | `cone` 直锥 / `tube` 折线弯角 | 牛角 4 点；羊角卷 5-6 点 | 弯角左右旋转取反 |
| 尾 | `tube` 折线 5 点 + 端帽球 | 猫尾 0.25-0.30，5 点弯曲 | **`tube` 无端盖**，末端必须球帽 |
| 喙 | `cone` rotX=-90 指 +Y | 长 ≈ 头径 0.5-0.8 | 轴反了 → 朝 -Y |
| 蹄/爪 | 压扁球 / 短 `cylinder` | 高 ≈ 腿径 0.4 | 落地 z = r×scale_z 或 depth/2 |
| 翼 | 压扁球整板 | 见 §4.6 | 水平翼在 front 几乎看不见 |

```python
tail = tube("cat_tail", [(0, -0.19, 0.19), (0, -0.26, 0.25), (0, -0.23, 0.40)],
            radius=0.011, resolution=8)
sphere("cat_tail_cap", radius=0.0115, segments=8, rings=6,
       location=(0, -0.23, 0.40), material=fur)     # tube 两端无盖 → 补球帽
```

### 4.4 对称件：一个循环建左右

- **适用/做法**：耳、眼、腿、翼、鳍、角、獠牙——所有成对部件。`for s in (-1, 1)` 里同时给位置与旋转：位置 `x = x0 * s`；**旋转 Y/Z 轴取反**（`ry*s`、`rz*s`），X 轴不变；命名带 `_{s}` 避免 join 重名。
- **参数/坑**：左右件必须同一套参数（不允许左耳 0.030 右耳 0.032）；中线件 x=0。坑：只镜像位置不镜像旋转 → 一只耳朝内一只朝外；`add_mirror` join 前要 apply，不如循环直观。

```python
for s in (-1, 1):
    ear = cone(f"cat_ear_{s}", radius1=0.030, depth=0.075, vertices=8,
               location=(0.042 * s, 0.225, 0.352), rotation=(-12, 12 * s, -18 * s),
               material=fur)                 # 位置 x*s，旋转 ry/rz*s
    parts.append(ear)
```

### 4.5 腿的粗细、关节与落脚（含贴合）

- **适用/做法**：四足站立的全部题材。腿 = `cylinder` 8 段，上端埋进躯干 15-20%、下端到 z≈0；猫/犬后腿可加一段大腿椭球做折角；脚掌压扁球中心 z = r×scale_z；蹄用短圆柱。相接件（腿-躯干、头-颈、耳-头、翼-肩、眼-头、尾-臀）必须**重叠 5-10 mm**。
- **参数/坑**：腿径 = 肩高 8-11%（猫狗）/6-8%（马鹿）；腿间距 = 躯干宽 0.55-0.65；前后腿 y 差 ≥ 体长 0.35。坑：腿太细 → 512px 下变一根线，至少 10-12 mm；四条腿同一 y → 侧视像两条；压扁球脚掌半埋穿地 → 查 `bbox_min`；完全埋进去 → 眼睛看不见。

```python
leg = cylinder("deer_leg", radius=0.010, depth=0.780, vertices=8,
               location=(0.085, 0.220, 0.390), material=fur)  # 上端埋进躯干
hoof = sphere("deer_hoof", radius=0.018, segments=8, rings=6,
              location=(0.085, 0.220, 0.018), material=hoof_mat)
scale_obj(hoof, (1.0, 1.3, 0.9))             # 底面 ≈ 0.0018 → 贴地
```

### 4.6 翅膀：翼板 + 翼尖（展翅首选）

- **适用/做法**：鸟、蝙蝠、龙、昆虫展翅。不要拼一排羽毛片：一块压扁球当**整片翼板**（span 拉长、厚度压到翼展 2-3%），肩部球过渡，翼尖单独一块小压扁球（深色）与翼板**重叠 40-50%**；整片绕肩 `rotY` 上反 15-25°。
- **参数/坑**：翼展 = 体长 2-3 倍；翼厚 = 翼展 2-3%；上反角 15-25°；后掠 `rotZ` 8-15°；翼尖长 = 翼板 30-40%。坑：水平翼（0°）在 `render_views` front/right（仰角 ≈12.4°）几乎侧对相机 → 看不见；内翼/外翼拆两件 → 中间裂缝；翼尖不重叠 → 黑片悬空。

```python
for s in (-1, 1):
    panel = ellipsoid(f"gull_wing_{s}", (0.155 * s, -0.005, 0.430), 0.085,
                      (1.60, 0.85, 0.22), wing)
    rotate(panel, y=-20 * s, z=-8 * s)           # 上反 20° + 后掠 8°
    tip = ellipsoid(f"gull_tip_{s}", (0.285 * s, -0.023, 0.478), 0.028,
                    (1.70, 0.80, 0.18), tip_mat)  # 与翼板重叠 40-50%
    rotate(tip, y=-20 * s, z=-8 * s)
    parts.extend([panel, tip])
```

### 4.7 翅膀的其它做法：羽片阵列 / 站姿折翼

- **羽片阵列**：`add_array(count=5-7, offset=(0.012, 0, 0))` 沿翼展排，或 for 循环 + 长度递减 + `rotZ` 扇形展开；单片羽长 = 翼长 1/3、宽 1/10、厚 2 mm，间距 ≤ 宽度 0.7（要重叠）。
- **站姿折翼 / 坑**：两块压扁椭球贴体侧（`rotY` 5°、离体 3-5 mm），翼尖在臀部上方交叉；鸟站姿常只露 2 条腿 + 3-5 片尾羽扇形。坑：羽片 >7 片面数翻倍（每片 8×6 球 ≈ 96 tris）；每片单独旋转易悬空 → 统一贴"翼根板"再叠羽尖。

```python
for i in range(5):                             # 长度递减 + 扇形展开
    f = ellipsoid(f"gull_feather_{i}", (0.10 + 0.026 * i, -0.01 - 0.008 * i, 0.43),
```

### 4.8 鱼：鱼身 + 鳍片 + 尾鳍

### 4.9 毛皮风格化：毛片 / 几何簇 / 配色分区

- **三档做法**：毛片（低模）沿背/颈放 3-6 片压扁锥或压扁球，颜色比主体深 10-20%，与主体重叠 30-50%；几何簇（卡通/毛绒）头/肩/尾各 4-8 个压扁球，半径 ≤ 头径 0.3；配色分区（最省面）腹/胸/脚掌浅色材质槽、背深色，斑点用薄压扁球贴面，虎斑用 2-4 条压扁细长球。
- **坑**：毛簇过多 → 面数爆炸 + 疣状；毛片与主体共面闪烁；颜色差太大变"补丁装"；低模优先材质分区，别用几何堆毛。

### 4.10 姿态参数化：站 / 坐 / 走 / 飞 / 游

- **做法/各姿态**：不要为每个姿态复制模型；在 `PARAMS["pose"]` 加参数，用"旋转+平移"实现，最后 `sit_on_floor(main)` 统一贴地。站=默认四腿垂直；坐（猫狗）=后腿折角（大腿椭球 `rotX` 30-45°、小腿缩短）、臀部落地、身体后仰 `rotX` -10~-20°、前腿伸直；走=对角腿前后错开 15-25°、身体轻 `rotZ` 2-3°；飞=翼上反 15-25°、身体 `rotX` 10-20°、腿收起后掠；游=鱼身 `rotZ` 3-5° 微摆、尾鳍偏转。
- **坑**：`rotate` 绕对象原点，腿会甩飞 → 先 `place` 再 `rotate` 或用 location 补偿；姿态后最低点不再是脚 → 用 `bbox_min` 或 `sit_on_floor` 重贴地；飞姿让翼尖穿地面。

```python
for s in (-1, 1):                              # 走姿：对角腿相位错开

                     location=(0.052 * s, 0.115, 0.085), material=fur)
    rotate(front, x=22 * s)                    # rotate 绕自身中心，不会甩飞
    parts.append(front)
```


## 6. 材质与配色

- `mat(color=...)` 写入 Principled BSDF 的**线性 Base Color**，不是 sRGB。换算：`c <= 0.04045 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4`；sRGB 0.55 → 线性 0.26，sRGB 0.80 → 0.60。
- 本机实测（AgX + 三点布光 + `setup_scene(distance=4.0)`）：中低饱和暖色**按 sRGB 直觉给会明显发白**——橘猫 sRGB 直觉 (0.80, 0.45, 0.20) 出图是粉色，压到线性 (0.32, 0.105, 0.028) 才是橘色。经验：**先把直觉色压暗 30-50% 再微调**；同名 `mat` 只建一次（不再改参数），多材质在 join 前分别 `assign`。

## 7. 灯光、相机与构图

- 机位：小型动物（猫/兔/鱼/昆虫）低机位 `elevation` 8-18°、`lens` 50、`distance` 2.5-4（太高会拍成"贴地饼"）；大型动物（马/鹿/牛）`lens` 85-135 长焦压缩、`elevation` 20-30°、`distance` 6-10，长腿不变形；鸟/飞行 `elevation` 25-40°，展翅必须给翼面上反角，否则 front/right 看不到翼面。
- `render_views` 的 front/right 是固定方向（仰角 ≈12.4°，`_VIEW_DIRECTIONS` 里 z=0.22），iso ≈29.5°；**`setup_scene(elevation=...)` 只影响初始相机，不影响 render_views 三视角**；要俯视翼面时改 `add_camera` + `fit_camera` + `render_still` 手动拍。
- 自动取景 `margin=1.15`：矮胖动物占高 45-55%、高瘦/展翅 85-90% 都属正常；主体异常小先查自建地台/离群件被算进 bbox。`distance` 同时决定灯距与光强：实测 `distance=2.0` 时 500 W key 距目标 1.6 m → 白猫/白鸟过曝发白，`distance=4.0` 正常；**小动物也要给 ≥3.5**，或显式 `setup_render(film_exposure=0.9, color_look="AgX - Medium High Contrast")`。
- 正面朝 **+Y**：吻/喙/胸在 +Y 侧、尾在 -Y；`+X` 是动物右侧（front 图里显示在画面左侧，别用画面左右描述朝向）。

| 尾巴/管状件末端一个黑洞 | `tube` 两端无端盖（`closed` 只连首尾） | 末端加球帽 r = tube 半径 ×1.05；或改用 `cylinder` |
| front/right 图里翼面"消失" | 薄翼水平（0°），front/right 仰角仅 12.4° 侧对相机 | 翼板 `rotY` 上反 15-25°；或另拍俯视 |
| 翼尖黑片悬空漂在旁边 | 翼尖与翼板不重叠 | 翼尖向体内移，重叠 40-50% |
| 内翼/外翼之间一条裂缝 | 翼拆成两件椭球 | 合并成一整块翼板，用材质/翼尖分色 |
| 材质发粉/发白 | 线性 Base Color 按 sRGB 直觉给（亮 30-50%）；或 `distance` 太小过曝 | 线性压暗 30-50%；`distance ≥3.5`；必要时降 `film_exposure` |
| 四条腿看着只有两条 | 前后腿 y 相同 | 前后腿 y 差 ≥ 体长 0.35 |
| 脚掌/蹄悬空或穿地 | 压扁球中心 z 没按 `r×scale_z` 算 | z = r×scale_z；查 `report.bbox_min[2]` |
| 一只耳/一只翼朝内 | 只镜像了位置没镜像旋转 | `rotation=(rx, ry*s, rz*s)`，统一 `for s in (-1,1)` |
| join 后倒角/平滑消失 | `join` 只保留首对象修改器 | join 前逐个 `apply_modifiers` |
